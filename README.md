# GoChain

GoChain is an educational blockchain implemented in Go. The project is designed to explore blockchain fundamentals through clear, incremental code while practicing Go, SQLite, concurrency, and testing.

> **Status:** Work in progress. This README will be expanded as implementation milestones are completed.

## Goals

GoChain will demonstrate:

- transactions and pending transactions;
- blocks, SHA-256 hashing, and chain linking;
- simple Proof of Work and mining rewards;
- blockchain validation;
- balances derived from confirmed blockchain history;
- SQLite persistence;
- mining cancellation with `context.Context`;
- a small command-line interface.

The project favors simplicity and educational value over production realism. It is not intended to be a production blockchain or cryptocurrency.
